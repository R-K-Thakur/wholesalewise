# **App Name**: WholesaleWise

## Core Features:

- Inventory Overview: Dashboard view showing current stock levels, purchase history, and sales trends.
- Product Input: Add new products with details like name, category, purchase price, wholesale price, retail price, units(gross, dozen), and quantity.
- Purchase Tracking: Record stock purchases, automatically increasing the stock levels.
- Sales Recording: Record sales, decreasing stock levels, with the option to mark wholesale vs. retail.
- Stock Level Alert: Based on historical sales data and current stock levels, this tool provides alerts for items needing reordering to prevent stockouts.
- Filter Products: Allows filtering and sorting the products based on product categories to monitor and track

## Style Guidelines:

- Primary color: Soft lavender (#D0BFFF), evoking organization and calm efficiency, as befits back-end inventory apps.
- Background color: Light gray (#F0F0F5), creating a neutral and clean backdrop.
- Accent color: Muted teal (#73A7B3), drawing attention to key actions and elements without overwhelming the user.
- Body and headline font: 'PT Sans', a friendly, readable sans-serif for clear information display.
- Simple, clear icons to represent different product categories and actions, aiding quick navigation and understanding.
- Clean, tabular layouts for data display, ensuring information is easily accessible and comparable.
- Subtle transitions and animations to provide feedback on actions, enhancing user experience without distracting from core tasks.
